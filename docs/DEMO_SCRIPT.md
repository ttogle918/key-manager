# 3분 시연 영상 — 스토리보드 & 대본 (KeyLens)

> 목표: **magic moment(어지러운 노션 화면 → 깔끔한 라벨 key-value)를 첫 30초**에. 총 ≤ 3분.
> 녹화 전 준비: `node scripts/dev.mjs` 로 백엔드+프론트 기동, 브라우저 `localhost:5173`.
> 데모 이미지는 전부 더미 값(`docs/demo/*.png`) — **실제 키는 절대 화면에 노출 금지**.
> 자막은 한국어, 나레이션은 선택(자막만으로도 전달되게 작성).

---

## 타임라인 요약

| 구간 | 시간 | 내용 |
|---|---|---|
| 0. 훅 | 0:00–0:30 | **문제 → 던지기 → 자동 분류**(magic moment) |
| 1. 문제 | 0:30–0:50 | 값만으론 구분 불가(같은 UUID 3종) |
| 2. 차별점 | 0:50–1:40 | 맥락 분류 + 신호 충돌 "확인 필요" |
| 3. 보안 | 1:40–2:30 | 암호화 저장 · 인증 · 잠금 |
| 4. 확장·마무리 | 2:30–3:00 | YAML 확장 + 로컬·오픈소스 |

---

## Scene 0 — 훅 (0:00–0:30) ★가장 중요

| 화면 | 자막 | 비고 |
|---|---|---|
| 어지러운 메모장/노션 스크린샷(키가 흩어진 모습) | "API 키, 이거 도대체 뭐가 뭔지…" | 2초 |
| KeyLens 입력 화면, `docs/demo/notion.png`를 **드래그해서 던짐** | "그냥 스크린샷을 던지면" | 브라우저에서 OCR 진행바 잠깐 |
| 결과 카드가 뜸: `NOTION_API_KEY`, `NOTION_DATABASE_ID` | "**무엇인지 알아서 분류합니다**" | 카드 클로즈업 |

> 첫 10초 안에 "던지기 → 라벨 붙은 결과"가 보이게. 설명은 나중에.

---

## Scene 1 — 문제 (0:30–0:50)

| 화면 | 자막 |
|---|---|
| 노션 화면에서 database ID / data source ID / page ID를 나란히 비춤 | "노션의 이 세 개는 **전부 똑같은 32자리 UUID**입니다" |
| 정규식 스캐너가 "여러 후보"라며 멈추는 이미지(도식) | "값만 봐선 구분이 안 돼요. 기존 도구는 여기서 손을 듭니다." |

---

## Scene 2 — 차별점: 맥락 분류 (0:50–1:40) ★핵심

| 화면 | 자막 |
|---|---|
| `docs/demo/notion.png` 결과에서 "Database ID" 라벨 → `NOTION_DATABASE_ID` 매핑 강조 | "KeyLens는 값이 아니라 **값 위에 적힌 라벨**을 읽습니다" |
| URL 입력에 `notion.so/…?v=…` 붙여넣기 → `database_id`로 분류 | "URL 구조도 신호입니다 — `?v=` 앞은 database ID" |
| (선택) `docs/demo/kakao.png` 던지기 → REST/Admin 각각 매핑 | "한 화면의 여러 키도 라벨로 각각" |
| **신호 충돌 카드**(같은 UUID가 두 해석) 시연 | "신호가 충돌하면? **단정하지 않고 '확인 필요'로** 후보를 보여줍니다" |

> 여기가 "기존 도구가 못 하는 지점". 신호 충돌의 "확인 필요"를 꼭 보여줄 것 — 정직함이 차별점.

---

## Scene 3 — 보안: 암호화 · 인증 (1:40–2:30)

| 화면 | 자막 |
|---|---|
| 결과 카드 "확정 후 저장" 클릭 → "AES-256-GCM으로 암호화되어 저장" 토스트 | "값은 **Argon2id + AES-256-GCM**으로 암호화되어 저장됩니다" |
| 보관함(대시보드) — 서비스별 그룹, 값은 마스킹 | "이 기기에만, 암호문으로" |
| 값 클릭 → 4초간 표시(복호화) | "인증 상태에서만 값을 봅니다" |
| **잠그기** → 값이 마스킹되고 "잠김" 표시 | "자동 잠금 · 무활동 시 잠금" |
| 잠금 해제에서 **틀린 비밀번호 → 거부** | "아무 비밀번호나 통과하지 않습니다 — 틀리면 복호화가 거부됩니다" |
| (선택) SQLite 파일을 텍스트 에디터로 열어 암호문만 보임 | "파일을 직접 열어도 평문 키는 없습니다" |

> "틀린 비밀번호 거부"는 강력한 신뢰 신호 — 꼭 포함.

---

## Scene 4 — 확장 & 마무리 (2:30–3:00)

| 화면 | 자막 |
|---|---|
| `knowledge/ollama.yaml` 파일을 잠깐 비춤 | "새 서비스 지원은 **YAML 한 파일** — 코드 수정 0" |
| 아키텍처 한 줄(로컬·서버 없음) | "외부 서버 없이 전부 내 기기 안에서" |
| 라이선스/오픈소스 문구 | "전부 MIT·허용적 라이선스. 오픈소스로 공개합니다" |
| 로고 + 한 줄 정의 | "**KeyLens — 맥락으로 정체를 가려, 나만 안전하게 보관**" |

---

## 녹화 체크리스트

- [ ] 실제 키·시크릿이 화면·클립보드·터미널에 노출되지 않는가 (더미만)
- [ ] 첫 30초에 "던지기 → 분류" magic moment가 담겼는가
- [ ] 신호 충돌 "확인 필요" 장면 포함(차별점의 정직함)
- [ ] 틀린 비밀번호 거부 장면 포함(인증 실체)
- [ ] 총 길이 ≤ 3분, 자막만으로도 이해 가능
- [ ] 배경음/나레이션은 선택 — 없어도 전달되게

> 녹화는 작성자가 직접 진행. 위 씬 순서대로 화면을 잡고 자막을 얹으면 된다.
