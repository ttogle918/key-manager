이 값이 무슨 키인지, 화면을 보고 알아냅니다

Notion의 database ID·page ID는 전부 똑같은 32자 UUID입니다. 값만 봐선 구분이 안 됩니다. KeyLens는 값 위에 적힌 라벨과 URL 구조를 읽어 정체를 가려내고, 암호화해 보관합니다.

Windows용 다운로드 소스 보기 무설치 실행 파일 · 계정 가입 없음
콘솔 스크린샷에서 본 것
Database ID
3f9a1c2e7b4d4e8a9c1f2d5e8a7b4c3f ← ?
Page ID
8b2d4f6a1c3e5a7b9d0f2e4c6a8b0d2f ← ?
내부 통합 시크릿
secret_••••••••••••••••
KeyLens가 정리한 것
NOTION_DATABASE_ID=3f9a1c2e…
NOTION_PAGE_ID=8b2d4f6a…
NOTION_API_KEY=(암호화 보관)

값이 같은 모양이어도 어디에 적혀 있었는지가 다릅니다. KeyLens는 그 차이를 읽습니다. 신호가 엇갈리면 임의로 단정하지 않고 두 후보를 보여줍니다.

키를 다루는 동안 생기는 사고를 막습니다

기능을 채운 게 아니라, 실제로 겪는 실패마다 대응을 붙였습니다.

분류

스크린샷·URL·텍스트에서 인식

콘솔 화면을 그대로 던지면 됩니다. OCR은 브라우저 안에서 돌아가 이미지가 기기를 떠나지 않습니다.

분류

공식 환경변수명으로 정리

NOTION_DATABASE_ID처럼 각 서비스가 실제로 쓰는 이름에 맞춥니다. 매번 다르게 적어 생기는 혼선이 사라집니다.

보관

암호화 금고

마스터 비밀번호로 잠급니다. 저장 파일을 직접 열어도 평문 키는 보이지 않습니다.

보관

자동 잠금 · 감사 이력

자리를 비우면 잠깁니다. 언제 무엇을 열람·복사·내보냈는지 기록이 남습니다 — 값은 남기지 않고요.

관리

살아있는 키인지 확인

버튼을 누르면 읽기 전용 호출 한 번으로 키가 아직 유효한지 확인합니다. 자동으로 호출하지 않습니다.

관리

노출 등급 표시

공개해도 되는 키와 절대 노출하면 안 되는 키를 구분해 표시합니다. 유출 시 피해와 대응 링크도 함께.

관리

만료 임박 알림

만료일을 넣어두면 임박한 것부터 위로 올라옵니다. JWT는 만료 시각을 자동으로 읽습니다.

이동

다른 기기로 옮기기

금고 전체를 암호화된 파일 하나로 내보냅니다. 서버를 거치지 않고 USB나 개인 클라우드로 옮기면 됩니다.

확장

새 서비스는 파일 하나

서비스 정의가 YAML이라 코드를 고치지 않고 추가할 수 있습니다. 현재 9종을 지원합니다.

키는 이 기기를 떠나지 않습니다

계정도, 클라우드도, 우리 서버도 없습니다. 분석과 보관이 전부 사용자 컴퓨터 안에서 끝납니다.

Argon2id
마스터 비밀번호에서 암호화 키를 유도합니다. 메모리를 많이 쓰도록 설계돼 대량 대입에 비용을 강제합니다.
AES-256-GCM
항목마다 개별 암호화하며 위조·변조를 함께 검증합니다. 비밀번호가 틀리면 복호화 자체가 거부됩니다.
저장되지 않는 것
마스터 비밀번호, 거기서 유도한 키, 평문 값. 디스크에는 암호문만 남습니다.
네트워크
백엔드는 127.0.0.1에서만 동작합니다. 키 유효성 확인을 직접 누를 때를 빼면 밖으로 나가는 통신이 없습니다.

정직하게 말하면: 이미 장악당한 컴퓨터(키로거·메모리 덤프)와 너무 쉬운 마스터 비밀번호는 막지 못합니다. KeyLens가 지키는 것은 기기 분실·파일 유출·저장소 직접 열람입니다. 그리고 마스터 비밀번호를 잊으면 복구할 방법이 없습니다 — 백도어를 두지 않았기 때문입니다.

설치

둘 중 편한 쪽을 고르세요.

실행 파일 (권장)

Windows용 실행 파일을 내려받아 압축을 풀고 KeyLens.exe를 실행하면 끝입니다. 설치 과정도, 계정 가입도 없습니다.

최신 버전 받기

소스에서 실행

Python 3.11+ 와 Node 20+ 가 필요합니다.

# 처음 한 번
cd backend && python -m venv .venv
.venv\Scripts\activate && pip install -r requirements.txt
cd ../frontend && npm ci && cd ..

# 실행 — 백엔드와 프론트가 함께 뜹니다
node scripts/dev.mjs

개발자용 — .env 파일 없이 키 불러오기

.env는 결국 평문 파일을 디스크에 남깁니다. keylens-env는 같은 한 줄 API를 쓰되 실행 중인 KeyLens 금고에서 그때그때 값을 받아옵니다. 

# 설치 (PyPI 아님 — 저장소에서 바로)
pip install "git+https://github.com/ttogle918/key-manager.git#subdirectory=keylens-env"

# 프로젝트 루트에 .keylens.toml
project = "블로그"

# 코드에서
import keylens_env
keylens_env.load_env()
os.environ["OPENAI_API_KEY"]

프로젝트마다 접근 범위가 나뉩니다. 등록되지 않은 디렉토리가 키를 요청하면 KeyLens 창에 승인 팝업이 뜨고, 허용한 프로젝트의 키만 내려갑니다.
